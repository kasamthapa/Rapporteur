```ts
async function attemptGeneration(...): Promise<GenerationAttempt> {
  const prompt = buildPrompt(title, agenda, lines, previousError);

  let raw: unknown;
  try {
    raw = await generateMeetingJson(prompt);
  } catch (err) {
    if (err instanceof GeminiInvalidJsonError) {
      return { success: false, error: err.message };   // only this one is swallowed into success:false

```

The `catch` block only special-cases `GeminiInvalidJsonError` (bad JSON from the model — a prompt-fixable problem). Every other error type, including `GeminiRateLimitError`, hits the bare `throw err;` and propagates out of `attemptGeneration` as a real exception, not a return value.
